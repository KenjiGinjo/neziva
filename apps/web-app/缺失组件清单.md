## ❌ 缺失的组件（需要安装）

### 1. **Select** - 下拉选择框
**用途**:
- 工作流列表的状态筛选 (`web-dashboard.html`)
- 执行历史的筛选 (`web-workflow-detail.html`)
- 日志级别筛选 (`web-workflow-logs.html`)

**安装命令**:
```bash
pnpm add @radix-ui/react-select
```

**需要创建**: `apps/web-app/src/components/ui/select.tsx`

---

### 2. **DropdownMenu** - 下拉菜单
**用途**:
- 用户头像下拉菜单 (`web-dashboard.html`)
- 工作流卡片的操作菜单
- 更多操作按钮

**安装命令**:
```bash
pnpm add @radix-ui/react-dropdown-menu
```

**需要创建**: `apps/web-app/src/components/ui/dropdown-menu.tsx`

---

### 3. **Table** - 表格组件
**用途**:
- 执行历史表格 (`web-workflow-detail.html`)
- API Keys 列表 (`web-settings.html`)
- 账单历史 (`web-billing.html`)

**注意**: Radix UI 没有 Table 组件，可以使用原生 HTML table 或安装第三方库

**方案 1 - 使用原生 table + 自定义样式** (推荐):
- 不需要额外安装，直接创建 `table.tsx` 组件

**方案 2 - 使用第三方库**:
```bash
pnpm add @tanstack/react-table
```
更强大的表格功能（排序、筛选、分页等）

**需要创建**: `apps/web-app/src/components/ui/table.tsx`

## 🚀 一键安装命令

### 必需组件（推荐安装）
```bash
cd apps/web-app

# Radix UI 组件
pnpm add @radix-ui/react-select @radix-ui/react-dropdown-menu @radix-ui/react-tooltip @radix-ui/react-popover @radix-ui/react-scroll-area

# 可选：如果需要更强大的表格功能
pnpm add @tanstack/react-table
```

### 完整安装（包含所有可选）
```bash
cd apps/web-app

# 所有 Radix UI 组件
pnpm add @radix-ui/react-select @radix-ui/react-dropdown-menu @radix-ui/react-tooltip @radix-ui/react-popover @radix-ui/react-scroll-area @radix-ui/react-separator

# 表格库（可选）
pnpm add @tanstack/react-table

# 骨架屏库（可选，或自定义实现）
pnpm add react-loading-skeleton
```

## 📝 组件实现优先级

### 高优先级（必需）
1. **Select** - 多处使用
2. **DropdownMenu** - 用户菜单必需
3. **Table** - 数据展示必需
4. **Tooltip** - 用户体验提升

### 中优先级（推荐）
5. **Popover** - 模板详情等
6. **ScrollArea** - 自定义滚动条

### 低优先级（可选）
7. **Skeleton** - 可以先用简单的加载状态
8. **Separator** - 已有 divider，可能不需要

## 📚 组件实现参考

所有组件都应该遵循 shadcn/ui 的设计模式：
- 使用 Radix UI 作为基础
- 使用 Tailwind CSS 进行样式定制
- 使用 `cn()` 工具函数合并类名
- 导出多个子组件（如 `CardHeader`, `CardContent` 等）

参考现有组件实现：
- `apps/web-app/src/components/ui/card.tsx`
- `apps/web-app/src/components/ui/button.tsx`
- `apps/web-app/src/components/ui/badge.tsx`
