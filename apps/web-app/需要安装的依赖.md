# 需要安装的依赖包

## 必需依赖

### 1. 图表库（用于工作流详情页）
```bash
pnpm add react-plotly.js plotly.js
pnpm add -D @types/plotly.js
```
**用途**: `web-workflow-detail.html` 中的执行趋势、成功率、平均时间图表

### 2. 工作流可视化编辑器（用于工作流编辑页）
```bash
pnpm add @xyflow/react
```
**用途**: `web-workflow-edit.html` 中的拖拽节点、连线功能
**替代方案**: 也可以使用 `react-flow` (旧版本) 或 `reactflow`，但推荐使用 `@xyflow/react` (最新版本)

### 3. Markdown 渲染（用于文档页）
```bash
pnpm add react-markdown remark-gfm
```
**用途**: `web-docs.html` 中的文档内容渲染
**可选增强**:
```bash
pnpm add rehype-highlight rehype-raw  # 代码高亮和原始 HTML 支持
```

### 4. 代码高亮（用于日志页）
```bash
pnpm add react-syntax-highlighter
pnpm add -D @types/react-syntax-highlighter
```
**用途**: `web-workflow-logs.html` 中的日志代码高亮显示
**替代方案**: 也可以使用 `shiki` (更现代，但需要服务端支持)

## 可选依赖（根据实际需求）

### 5. 日期格式化增强
```bash
pnpm add date-fns  # 已安装，但可能需要更多功能
```
**用途**: 日期时间格式化（已存在，确认是否足够）

### 6. 虚拟滚动（如果列表数据量大）
```bash
pnpm add @tanstack/react-virtual
```
**用途**: 工作流列表、执行历史等长列表的性能优化

### 7. 拖拽排序（如果需要在列表中使用）
```bash
pnpm add @dnd-kit/core @dnd-kit/sortable @dnd-kit/utilities
```
**用途**: 节点库中的拖拽功能（如果 @xyflow/react 不满足需求）

## 安装命令（一次性安装所有必需依赖）

```bash
cd apps/web-app

# 必需依赖
pnpm add react-plotly.js plotly.js @xyflow/react react-markdown remark-gfm react-syntax-highlighter

# 类型定义
pnpm add -D @types/plotly.js @types/react-syntax-highlighter

# 可选增强
pnpm add rehype-highlight rehype-raw
```

## 注意事项

1. **图标库**: HTML 中使用了 FontAwesome，但项目已有 `lucide-react` 和 `@haole/svg`，建议：
   - 优先使用现有的 `lucide-react` 图标
   - 如果必须使用 FontAwesome，可以安装：
     ```bash
     pnpm add @fortawesome/react-fontawesome @fortawesome/free-solid-svg-icons @fortawesome/free-brands-svg-icons
     ```

2. **图表库选择**:
   - `react-plotly.js` 功能强大但体积较大
   - 如果只需要简单图表，可以考虑 `recharts` (更轻量)
   - 如果选择 `recharts`:
     ```bash
     pnpm add recharts
     ```

3. **工作流编辑器**:
   - `@xyflow/react` 是 `react-flow` 的新版本，API 更现代
   - 如果遇到兼容性问题，可以回退到 `react-flow`:
     ```bash
     pnpm add react-flow
     ```
